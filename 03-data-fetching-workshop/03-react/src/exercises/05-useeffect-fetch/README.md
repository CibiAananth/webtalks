# Exercise 05: useEffect + fetch

Build the useEffect + fetch pattern step by step.

## How to run

```bash
cd 03-react
npm install
npm run dev
```

Open http://localhost:5173/05 and work through Steps 1-4.

## Files to edit

- `src/exercises/05-useeffect-fetch/steps/Step1.tsx`
- `src/exercises/05-useeffect-fetch/steps/Step2.tsx`
- `src/exercises/05-useeffect-fetch/steps/Step3.tsx`

Step 4 is the complete reference implementation.

## Learning objectives

1. Understand the basic useEffect + fetch pattern
2. Add loading state for better UX
3. Add error handling (remember: fetch doesn't throw on 404!)
4. See the full pattern with cleanup
