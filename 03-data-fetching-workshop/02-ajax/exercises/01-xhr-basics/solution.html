01. XMLHttpRequest Basics — Solution

Complete the fetchUsers() function to load team members using raw XMLHttpRequest. Open DevTools Network tab to observe the request.

What's happening here

This solution uses XMLHttpRequest to fetch data without reloading the page. The key flow is: create XHR → configure with open() → set up onreadystatechange handler → send() the request. The handler watches for readyState === 4 (complete) and status === 200 (success), then parses the JSON response and updates the DOM. This pattern was revolutionary in 2005!
