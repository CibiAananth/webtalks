Part A — Simple jQuery AJAX

Raw XHR took 30 lines. jQuery's $.get() does it in 5.

What's happening here

jQuery's $.get() wraps XMLHttpRequest in a clean API. The same request that took 30 lines of raw XHR is now 5 lines. jQuery also handles browser inconsistencies — IE, Firefox, and Chrome all had slightly different XHR implementations, and jQuery smoothed them over. This is why jQuery became so popular in the 2006-2015 era.

Part B — Nested Callbacks (The Pyramid of Doom)

Fetch user → then their posts → then comments on the first post. Each request depends on the previous. Watch the waterfall in the Network panel.

This is callback hell

Three levels of nesting, each dependent on the previous result. Notice: the indentation keeps growing to the right. Error handling is scattered across three separate .fail() handlers. Adding a fourth request would mean a fourth level of nesting. And if you wanted to add a loading state for each step, or handle partial failures gracefully, the complexity explodes. This is the exact pain that Promises were designed to solve.
